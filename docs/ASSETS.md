# Gestaltung und Bildrechte

Fahrzeugsilhouette und App-Symbol sind eigens für dieses Projekt in SVG gezeichnet. Keine Hersteller- oder Händlerfotos, keine behauptete konkrete Scala-Modellvariante. Der Hinweis „Neutrale Illustration“ ist sichtbar. Das eigene Fahrzeugfoto kann als unverändertes Original hochgeladen, ausgewählt und durch ein anderes ersetzt werden.

Symbole: lucide-react (ISC-Lizenz, siehe installiertes Paket und Lockfile). Verwendet wird die lokale Systemschrift; keine externen Fonts. React/TypeScript/Vite und Bibliotheken unter ihren jeweiligen Paketlizenzen. Eine spätere Karte benötigt eigene Prüfung von Bibliothek, Tiles und Attribution; derzeit keine Karte oder eingebettete Tankpreis-Webseite.
